## Codex 常见使用问题解答

### 1. 如何查看 Windows 电脑是 ARM 架构还是 AMD64 架构？

查看电脑架构有多种方法。最直观的方法是按下 `Win + R`，输入 `cmd` 并回车，在命令提示符中执行：

```bat
echo %PROCESSOR_ARCHITECTURE%
```

命令会返回 `AMD64`、`ARM64` 等系统架构信息。

### 2. Codex 默认安装在 C 盘，如何移动到 D 盘？

可以在安装前更改 Microsoft Store 应用的默认安装位置：按下 `Windows + I` 打开设置，进入“系统 → 存储 → 更改新内容的保存位置”，把“新的应用将保存到”从 C 盘改为 D 盘，然后再安装 Codex。

如果已经安装，可以在 Windows 的“已安装的应用”页面中找到 Codex。系统支持时，打开应用的更多选项并选择“移动”，即可迁移到其他磁盘。

### 3. Codex 能不能接入国内模型，例如 DeepSeek？

OpenAI 官方客户端默认使用官方支持的模型和服务。一些第三方开源工具可以帮助管理兼容接口，例如：

- CC-Switch：[https://github.com/farion1231/cc-switch](https://github.com/farion1231/cc-switch)
- Codex++：[https://github.com/xianyu110/CodexPlusPlus](https://github.com/xianyu110/CodexPlusPlus)

第三方接口的模型能力、数据留存、稳定性和计费规则由对应服务提供方负责。导入 API Key 前，应先核对项目来源和接口域名。

### 4. 使用邮箱注册的 OpenAI 账号登录 Codex 时需要手机号怎么办？

请优先按照 OpenAI 当前登录页面提供的验证方式完成账号认证。如果客户端提供“使用其他方式登录”，也可以根据界面提示选择当前账户支持的认证方式。API Key 与 ChatGPT 订阅是不同的计费和权限体系，使用前请确认账户余额与调用规则。
