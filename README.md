## Codex 客户端下载

网站首页提供 Codex 客户端下载入口：

[https://pan.quark.cn/s/0f1763fe2ac9?pwd=rTQw#/list/share](https://pan.quark.cn/s/0f1763fe2ac9?pwd=rTQw#/list/share)

也可以通过 npm 安装 Codex CLI：

```bash
npm i -g @openai/codex@latest
```

Windows 用户可以在 CMD 或 PowerShell 中执行，macOS 和 Linux 用户可以在终端中执行。安装完成后，按照网站教程完成登录和初始化配置。

Codex 客户端、CLI 命令和模型支持可能随着官方版本更新而变化，实际使用时请以官方发布状态和账号页面显示为准。
